## Demonstrated gap and repair

Before implementation, G07 transported a C07 `cement_operator` whose independent client volume differed from the same run's C02 operator. The baseline negative failed with **`Crossed C07 recipe reached transport`**. This establishes a G07 binding defect, not an engineering-formula defect. The new gate refuses crossed Lab job/mud/active identities, mismatching/unadmitted C02 or configured C05 references, and disagreement with committed observations/confirmation before C07 transport. Rejected C07 inputs retain unrelated C02/C05 results and cannot produce a completed-Lab success.

On successful C07 comparison, G07 independently checks the source pin, exact typed Lab operator digest and template SHA. The frozen receipt adds `lab_admission`, containing `SOURCE_ADMITTED_PARTIAL_REFERENCE`, the exact operator SHA and original `payload_admitted_by_fluid` flags. A source-valid partial reference is not a complete Lab payload, a physical Word match or a program PASS. Receipt/session/document/revision invariants remain the existing authorities.

The baseline UI exposed only conditions, selected scalar observations and cement context. The authorized additions stay inside the existing optional Lab expander. Existing C07 already owns fitting, validation, admission, Word projection, recipe masses and physical binding; those implementations were reused.
