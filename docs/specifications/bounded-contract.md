# Bounded input/output and dependency contract

Public module/test bytes match the accepted C01R–C04 identities. No new parser/engine feature is introduced. C01R `parse_docx` emits ordered EXTRACTED_UNVERIFIED structural claims with document SHA, original locator, raw text and conservative identity. C02 uses independent canonical job/active-fluid/per-slurry client volume, density, explicit base identity/SG and additive properties; genuine pinned automatic source functions calculate references. No geometry or mandatory inactive-fluid input is introduced.

C03 accepts those operator inputs and a DOCX, requiring one proved Data→Blend→Additives→adjacent preparation NOTE group and eligible source tank. Full-precision pure water comes from original mass balance. Inference retains nominal subtraction and compatible source-display interval. Solution is separate. Gross rows use original `build_cement_tables`, salt/classification and source display. No inferred physical heel or automatic total-water PASS exists.

C04 additionally accepts exactly `{slurry, corrected_dead_volume_bbl}`. A finite nonnegative explicit proposal applies only to the named proved ordinary slurry. Original C03 and unselected slurry findings remain intact. Preparation water and genuinely dependent gross additive quantities use original source. Base recipe/Yield/Sacks/pure water/Lab reference stay invariant; unexpected dependency is an engineering STOP. Before is inferred/nonunique; after is conditional source calculation. No Word output or guessed Procedure/numbered NOTE is produced.

JSON success is PARTIAL_FINDINGS_ONLY. MATCH is one supported claim only; unmapped records remain UNIMPLEMENTED/NOT_VERIFIABLE. Missing, zero, dash, N/A, malformed and ambiguous differ. Unsupported CT/Spacer/Scavenger roles, duplicate/contradictory notes, wrong tanks/units, stale hashes and invalid edits cannot silently apply a correction. No measured-Lab prediction, physical capacity rule or second formula engine exists.

Runtime packaging preserves relative module paths and accepted hash pins. `tools/provision.py` downloads exact locked external bytes, regenerates private synthetic control inputs and writes no App/accepted source. New module-specific pytest temp factories allow native execution inside the accepted path boundary without altering tests. Runtime-generated historical filenames denote new equivalent controls, not original historical evidence. Source-template media/metadata never enter the public file inventory.
