## Public library / private runtime interface

Run the provisioned runtime, not a Git checkout. Input and output DOCX and CLI JSON
files must be under its `tmp/`, with real paths, no symlink/worktree escape. Linux
directory descriptors, `/proc/self/fd` and atomic no-clobber hard links are required;
an unsupported filesystem/platform fails closed. Output must not already exist.

```python
from c10_corrections import propose, apply
preview = propose(original_docx, independent_c02_operator)
# Human explicitly enumerates exact SELECTABLE proposal objects; never select all by default.
request = {"schema": "c10.1", "bindings": preview["bindings"], "selected": [chosen_proposal]}
result = apply(original_docx, independent_c02_operator, request, new_docx)
```

```sh
python -B c10_corrections.py tmp/operator.json tmp/original.docx
python -B c10_corrections.py tmp/operator.json tmp/original.docx --selection tmp/selection.json --output tmp/corrected.docx
```

`propose` is read-only. A selection is not a trusted finding/locator receipt: the
worker recalculates the unchanged genuine C02 comparator and original App reference
from independent inputs, checks the exact complete proposal again, and refuses stale
document/operator/source/template/field/slurry/locator/raw-text/replacement bindings.
Finding ID binds this evidence; it is not reviewer authentication or Golden admission.
Changing a Checker reference generates new expectations, not a repaired Word claim.

The original pure reference functions run in a new subprocess with the same
direct-original-reference bridge as accepted C03. Only the comparator's process/cache
wrapper is replaced in that private child; source functions, algorithms and findings
are unchanged. Source calls include `build_components`, `calculate_base_results`,
`calculate_slurry_from_components`, `build_cement_tables`, and original Word quantity
projection. All 143 source/blob hashes and accepted identities are checked before
work and again before publication. Network is denied; writes are restricted to
private runtime `tmp/` and `cache/`; no live Streamlit session is used.

## Supported edits and preservation proof

- Only a fresh C02 `DISCREPANCY`, `IDENTIFIED` ordinary cement Yield/Sacks claim is
  selectable. No automatic CT/Squeeze/Scavenger/special-fluid edit. This is correction
  coverage, not a new App job/fluid applicability rule. Client volume remains authoritative.
- Replacement is the exact original source display (`yield_cuft_sk` plus its proven
  printed unit, or original base blend `sks or lbs` text), not a user-derived number.
- Physical Cementing Program heading, unique table title/identity, original row,
  unmerged regular grid cell, one paragraph/run/text node and literal style ancestry
  must be proved. Nested/merged/duplicate/hidden/numbered/field/control/hyperlink,
  complex/split runs, unknown styles and protected/tracked documents fail closed.
- XML parser byte offsets identify the selected `w:t`; only those text bytes change.
  No global replacement, paragraph/table rebuild or whole-XML serialization occurs.
  Other ZIP member contents, order, archive comment and member metadata are checked
  unchanged (CRC/length/compression length and container offsets necessarily differ
  for the changed member). ZIP variants whose metadata cannot be preserved are refused.
- A private staged file is reopened with C01R and C02/source recheck. Selected claims
  must MATCH their exact replacement; every unselected C02 finding/locator/status/raw
  value must remain identical except document SHA. All raw C02 claims remain indexed.
  Source references must remain equal. A failed recheck cannot publish a copy.
- Original bytes, independent operator and any CLI JSON byte bindings are checked
  immediately before atomic no-clobber output publication. Temporary staging is removed
  on success/refusal. Rejected transactions do not leave a partial output or overwrite input.

`PARTIAL_FINDINGS_ONLY` always remains. `COPY_CREATED` describes an atomic file
transaction, not complete engineering correction. `dependency_group_complete` remains
false. C03–C09 rechecks needing other independent references are explicitly
`NOT_VERIFIABLE`, not silently counted repaired. Existing C04 preview is unchanged;
its gross/NOTE/procedure locations are not auto-editable in this first subset.
Measured Lab, arbitrary prose, C04 water/NOTEs, Spacer/CT solvers and full cascades
remain `MANUAL_CORRECTION_REQUIRED` / unverified, including unselected group members.
