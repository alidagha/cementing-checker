# Checker zero-regression contract

One owner-approved bounded unit at a time. Accepted C01R–C04 identities are preserved in `accepted.lock.json`; later components are authorized only by their own owner-approved Batch/specification, and no engineering redesign is implied. Packaging may add paths/tooling without changing calculation or extraction semantics; a substantive parent change requires new scope.

Never weaken or skip accepted assertions, fabricate baseline failures, infer missing engineering properties, add physics/tank limits, synthesize lab measurements, or label partial findings an overall PASS. Preserve source precision, independent client volume and pure Mix Water versus total preparation water. Preserve original document bytes and complete C03 results in C04; inferred before uncertainty differs from explicit proposed after DV.

Verify upstream lock, accepted hashes, input bytes and write isolation before running. All caches/temp/generated fixtures belong in a separate private runtime. Source/template bytes are externally obtained and verified, never silently upgraded. Missing/zero/dash/N/A/malformed/ambiguous remain distinct. Unsupported association fails closed. Do not modify live App or accepted ancestors.

Necessary tests must run on final effective bytes, with negative controls and exact FRESH/PREVIOUS/NOT RUN reporting. No skip/xfail, no tautological expectations, no historical RED claim from regenerated fixtures. Native collection must equal the union of three unique whole-module shards; source/schedule tampering and missing phase evidence must fail. Local draft evidence is not hosted regression certification.

Full App regression needs independent authority. Remote CI and publication follow the pipeline mode of the active Owner-approved Batch prompt citing Collaboration Charter v5.4 rev1 (Codex Operative Card §4); without such a prompt they need independent authority. Branch/ruleset/workflow changes and merges to `main` always need independent authority (merge: Independent Architect `ACCEPTED` on the exact Head SHA). Stop for real engineering uncertainty, unsupported migration, unsafe content/isolation, unresolved meaningful failure, expired cost authority or any unauthorized mutation. Keep all originals/recovery; never destructively restart. After local review, stop before publication unless the active Owner-approved Batch prompt cites v5.4 rev1 and specifies a pipeline mode; then complete the Batch according to that mode.
